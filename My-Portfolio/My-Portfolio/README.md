# My Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Structure
- `index.html` — main page
- `css/style.css` — design
- `js/script.js` — interactions
- `assets/images/profile.jpg` — profile photo
- `assets/resume/Resume.pdf` — resume

## Before publishing
1. Replace `assets/images/profile.jpg` with your photo.
2. Replace `assets/resume/Resume.pdf` with your resume.
3. Update email, GitHub and LinkedIn links in `index.html`.
4. Add real GitHub links to the project cards.

## Hosting
This project is ready for GitHub Pages.
